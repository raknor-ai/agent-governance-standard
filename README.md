## About

Operationalized agent-governance criteria with adversarial testing scenarios. 26 controls across 5 domains. Compliance is assessed through adversarial testing against live systems and verified through cryptographic evidence.

The document in this repository (`STANDARD.md`) is the v1.0 text as served on 2026-08-19.

**SHA-256**: `01fae0e01d6e7dee4ec90041e1bf89fbd67b956425ee13d565bac4c72595b603`

## Comment Process

The standard's own Section 14 commits to publishing proposed changes for comment before adoption. This repository will carry that process for v1.1.
